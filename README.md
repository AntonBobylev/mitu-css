# mitu-css

Практическая работа по дисциплине «CSS и верстка».

## Структура проекта
* `index.html` — файл с базовой семантической разметкой формы авторизации.
* `style.css` — таблица стилей сброса, позиционирования и оформления элементов.

## Инструкция по запуску
1. Клонируйте репозиторий или скачайте архив с исходным кодом.
2. Запустите файл `index.html` в браузере.
